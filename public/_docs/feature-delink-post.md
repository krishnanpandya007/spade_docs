# **De-Linking Post**
--------------------------


# [*Motive*](#delink-motive) 
----------------------------------------------

While having and gaining new hacks, sometimes we need to free up some posts linking to your account. Now instead of deleting them completely, which is totally useless afterwards (Because it's a hack after all). 


# [*Concept*](#delink-concept) 
--------
You can de-link your posts, so then it completely disconnects from your profile whitout leaving any trace stored in our system. However Spade created a static public collection profile/account for this de-linked posts that have been removed from some profile instances. So this Collection account now contains all those posts which are removed from profiles.


# [*Steps (Internally)*](#delink-steps) 
-----------
* De-link post from your profile
* Link to delinked collection 
* Process Successfull
